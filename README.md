# FSB Core

원본 게임 엔진의 디컴파일 결과를 바탕으로 동작을 재현한 C++20 프로젝트입니다.
게임 로직, 렌더링, 오디오, 스크립트 실행을 구현하며, 일부 코드는 원본의 저수준 구조를 유지하고 있습니다.
원본과의 완전한 동등성 검증은 아직 완료되지 않았습니다.

## 빌드

CMake 3.20 이상과 C++20 컴파일러가 필요합니다. 아래 구성은 SDL3 게임 실행 파일까지 빌드합니다.

## 리소스 및 테스트

원본 게임 리소스, 실행 파일, 비교용 덤프는 포함하지 않습니다.
게임 실행에는 별도로 준비한 원본 리소스가 필요합니다.
원본 자료가 필요한 테스트는 해당 자료가 있을 때만 등록되며, 자료가 없으면 자체 완결형 테스트만 실행됩니다.
